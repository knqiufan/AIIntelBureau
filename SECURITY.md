# Security policy

Do not report vulnerabilities in public issues or include credentials, private memory text, logs, database exports, or request captures. Report privately to the repository maintainers through GitHub's private security advisory flow. Include reproduction steps, impact, affected revision and a safe contact method; an acknowledgement target is five business days.

Supported releases are the latest `main` release tag and its documented hotfixes. Rotate any affected credentials outside this repository before sharing diagnostic material.
