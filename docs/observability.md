# 可观测性、SLO 与告警

`GET /metrics` 是仅限 API 内网的 Prometheus exposition；浏览器代理不会路由它。结构化 stdout 日志携带 `X-Request-ID`，且只包含 allow-list 字段，不含 Cookie、口令、问题或记忆正文。

## 最小仪表盘

- 请求量、4xx/5xx 计数和 p95（由入口代理/OTel 采集）。
- `/api/readyz` 成功率；活跃 SSE 连接；SSE 重连率（代理访问日志）。
- LLM/检索延迟、降级次数、429 配额拒绝、远端清理待办与存储容量。
- 容器重启、SQLite 卷容量和远端 seekdb/LLM 健康状态。

## SLO 与告警

| 信号 | 目标 | 触发与处置 |
| --- | --- | --- |
| readyz | 30 天 99.5% | 连续 2 分钟不可用：值班人检查内存服务、配置及最近发布，必要时回滚。 |
| API 5xx | 5 分钟低于 1% | 触发告警并按 request ID 查脱敏日志；不要索取请求正文。 |
| SSE | 5 分钟重连率低于 2% | 检查代理超时、心跳和网络；游标重连不得从 0 重放。 |
| cleanup | 待办为 0 | 超过 15 分钟：暂停数据删除声明，重试远端清理并记录结果。 |
| LLM | 预算不超限 | 接近 80% 通知；耗尽时保持确定性证据模式，不无限重试。 |

每次告警演练与事故复盘均记录负责人、时间线、影响、恢复依据和后续项；链接到 [备份、恢复与发布](./backup-and-release.md)。
